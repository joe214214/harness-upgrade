# 日常使用速查

## 启动

```powershell
cd D:\grauate_study\relay_3\relay

docker compose up -d                      # mock 后端（秒起，验证链路用）
docker compose --profile gpu up -d        # 真模型（1-2 分钟，模型已缓存）
```

第一次之后**不要再跑 bootstrap.ps1**，它会重复建 key。直接 `docker compose up -d`。

## 关闭

```powershell
docker compose --profile gpu down         # 停止（数据和模型缓存都保留）
```

## 确认状态

```powershell
docker compose ps                         # 哪些服务在跑
curl http://localhost:8000/readyz         # 网关是否就绪
docker compose logs -f worker-gpu         # 看 worker 日志（显存账本、模型加载）
```

## 拿凭证

admin token 在 `.env` 里：

```powershell
Get-Content .env | Select-String ADMIN
```

API key 丢了就重建（或在控制台 API keys 页点创建）：

```powershell
$admin = (Select-String -Path .env -Pattern "^RELAY_ADMIN_TOKEN=(.*)$").Matches[0].Groups[1].Value
(Invoke-RestMethod -Method Post http://localhost:8000/admin/keys `
  -Headers @{"X-Admin-Token"=$admin} -ContentType "application/json" `
  -Body '{"name":"me","rpm_limit":120}').key
```

## 换 profile

改 `.env` 的 `RELAY_MODEL_PROFILE`，然后只重启 worker：

```powershell
docker compose --profile gpu up -d --force-recreate worker-gpu
```

| profile | 显存 | 能做什么 |
|---|---|---|
| `compact` | 4.5 GB | 对话 + 看图（笔记本用这个） |
| `voice` | 5.5 GB | 对话 + 转写 + 朗读（没有视觉） |
| `balanced` | 7.3 GB | 全都有（需要桌面占用 < 0.7 GB） |

换 profile 不用重新下载模型，缓存在 `hf-cache` volume 里。

## 改了代码之后

```powershell
docker compose up -d --build gateway      # 只重建改动的服务
docker compose up -d --build web
```

改后端改得频繁的话，用本地开发模式更快（自动热重载），见 README。

## 清理

```powershell
docker compose --profile gpu down -v      # 连数据库和模型缓存一起删（慎用，模型要重下 3-5 GB）
docker system prune -a                    # 删掉所有未使用的镜像，释放磁盘
```
